# 車検・メンテ記録アプリ

車検・オイル交換・タイヤ交換など、車のメンテナンスの「実施日」と「費用」を記録すると、**次回の目安時期を自動で教えてくれる**Webアプリです。
単一のHTMLファイルで動き、スマートフォンでもそのまま使えます。データはブラウザ内（localStorage）に保存されます。

> ポートフォリオ3作目として作成。「車のメンテナンス時期を忘れがち」という身近な困りごとを、記録と自動計算で解決するのがコンセプトです。

## 機能

- **車両の登録（複数台対応）**
  - 名前／愛称、車種、初度登録年月、現在の走行距離、メモを登録
  - ヘッダーのプルダウンで表示する車を切り替え可能
- **メンテ記録の追加・編集・削除**
  - 種類：車検／オイル交換／オイル＋フィルター／タイヤ交換／タイヤローテーション／バッテリー交換／エアコンフィルター／ワイパー／その他
  - 実施日、費用、走行距離（任意）、お店（任意）、メモ（任意）
  - 車検の記録では「車検満了日（任意）」も入力でき、車検証の日付をそのまま次回目安に使えます
  - 種類で絞り込み表示が可能
- **次回目安の自動計算（ホーム画面）**
  - 種類ごとの標準間隔から次回時期を計算し、「あと○日」「期限切れ（○日超過）」を表示
  - 車検の次回目安の優先順位：**満了日（入力値）＞ 前回実施日＋2年 ＞ 初度登録＋3年（初回車検）**。満了日ベースのときはカードに「満了日（入力値）」と表示されます
  - 期限切れは赤、30日以内（または残り500km以内）は橙で色分け
  - 距離ベースの目安（例：オイル交換 5,000km）も、現在の走行距離とあわせて残り距離を表示
  - 緊急度順に並び替えて表示
- **費用の集計**
  - 選択中の車の総額、年別合計、種類別合計を表示（全車両の合計も併記）
- **データのバックアップ**
  - JSON形式で書き出し／読み込みが可能（機種変更・ブラウザのデータ消去対策）
- **サンプルデータ**
  - 設定タブのボタン1つで、表示の様子を確認できるサンプル車両と記録を読み込めます

## 使い方

1. 「設定」タブで車両を登録します（初度登録年月を入れると、初回車検の目安が計算されます）。
2. メンテナンスを受けたら「記録」タブから実施日と費用を追加します（車検のときは、車検証に記載の満了日も入力すると次回目安がその日付になります）。
3. 「ホーム」タブで次回の目安を確認します。走行距離が増えたら、ホームの「現在の走行距離」を更新すると距離ベースの目安も更新されます。
4. たまに「設定」タブからバックアップを書き出しておくと安心です。

## 次回目安の間隔と根拠

いずれも**一般的な目安**であり、車種・使い方・メーカー推奨によって変わります。実際の交換・点検時期は、取扱説明書や整備工場の判断を優先してください。

| 種類 | 目安 | 根拠 |
|---|---|---|
| 車検 | 初回3年・以降2年（満了日入力があればそれを優先） | 自家用乗用自動車の車検（継続検査）は、新車の初回が3年、その後は2年ごと（道路運送車両法に基づく一般的な周期）。次回目安は、①車検記録に入力された満了日（車検証の日付）→ ②前回車検の実施日から2年後 → ③記録がない場合は初度登録から3年後、の優先順位で決まります。実施日から単純に2年足すと実際の満了日とずれることがあるため、満了日を直接入力できるようにしています |
| オイル交換 | 6か月 または 5,000km | エンジンオイルは一般に「半年または5,000km」が交換目安とされることが多い（メーカー推奨は車種により5,000〜10,000km／半年〜1年と幅があるため、安全側の目安を採用） |
| オイル＋フィルター | 1年 または 10,000km | オイルフィルターは「オイル交換2回に1回」が一般的な目安とされるため |
| タイヤ交換 | 4年 | タイヤのゴムは走行距離が少なくても経年劣化するため、使用開始から4〜5年が交換検討の目安とされることが多い（タイヤメーカーは5年での点検、10年での交換も案内） |
| タイヤローテーション | 6か月 または 5,000km | 偏摩耗を防ぐため、5,000km前後での位置交換が一般的な目安とされるため |
| バッテリー交換 | 3年 | バッテリーの寿命は一般に2〜3年とされるため（使用環境で大きく変動します。3年を過ぎたら即故障という意味ではありません） |
| エアコンフィルター | 1年 または 10,000km | 一般に「1年または10,000km」が交換目安とされるため |
| ワイパー | 1年 | ワイパーゴムは劣化しやすく、半年〜1年が交換目安とされるため |
| その他 | 自動計算なし | 前回実施日のみ表示します |

## 技術メモ

- 単一HTMLファイル（HTML／CSS／JavaScript、フレームワーク不使用）
- データ保存：localStorage（キー `carMaintenanceApp.v1`）、JSONバックアップ対応
- 日付計算はタイムゾーンの影響を受けないよう、年月日の文字列ベースで実装（月末日の調整あり）
- レスポンシブデザイン（スマートフォンでの利用を想定）

## 今後の拡張案

## 注意事項

- 表示される次回時期はすべて「目安」です。安全に関わる部品については、早めに整備工場へご相談ください。
- データはブラウザ内にのみ保存され、外部サーバーには送信されません。
